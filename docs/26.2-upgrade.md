# Minecraft 26.2 客户端移植

维护分支 `26.2/main` 从 `26.1/main` 的 `f7bdb0a` 开始，客户端版本为
`0.18.0-beta.2-thw.26.2`。原 26.1 分支保留。当前构建目标为 Fabric；
`settings.gradle.kts` 中的 NeoForge 模块仍未启用，其旧配置不表示 26.2 支持。

## 构建与安装

使用 Java 25：

```sh
./gradlew build --no-daemon
```

产物：`fabric/build/libs/feathermorph_client-fabric-26.2-0.18.0-beta.2-thw.26.2.jar`。
模组声明只接受 Minecraft 26.2，资源包格式为 88.0。

| 组件 | 本分支使用版本 |
| --- | --- |
| Java | 25 |
| Gradle / Fabric Loom | 9.4.1 / 1.16.3 |
| Fabric Loader / API | 0.19.5 / 0.161.0+26.2 |
| Cloth Config / Mod Menu | 26.2.155 / 20.0.3 |
| EMF（可选） | 3.3.11，Modrinth `tgEvvPhr` |
| ETF（可选） | 7.2.5，Modrinth `b9RlCI9F` |
| EntityCulling（可选） | 1.11.3，Modrinth `uXe0pIaz` |

依赖版本已通过 Maven、Modrinth 和 Mojang 的 26.2 版本元数据核对。
CI 使用 Java 25，并只上传实际启用的 Fabric 构建。

## 项目结构

| 部分 | 主要职责 |
| --- | --- |
| `fabric` | Fabric 入口、平台事件、客户端指令、Mod Menu、第一人称手部 Mixin |
| `common/client/network` | V3 JSON 握手和命令；保留 V1/V2 回退 |
| `ClientMorphManager` / `DisguiseInstanceTracker` | 当前形态、服务端公布的他人形态、实体与同步器生命周期 |
| `EntityCache` / `syncers` / `properties` | 本地伪装实体、位置与动作同步、命名属性解析和应用 |
| `graphics` / `screens` / `mixin` | 世界与手部渲染、HUD、背包预览、形态及表情界面 |
| `common/server` | 可选单人调试服务器，不是相邻目录的 Paper 插件 |

## 26.2 API 改动

- 实体常量从 `EntityType` 移至 `EntityTypes`。所有当前启用模块中的引用已迁移。
- 移除的 `EntityType.byString` 由共享注册表查询替代。无效标识符和未知类型保持为空，
  不使用默认实体替代；客户端及内置单人服务器三处调用均使用同一查询。
- 新建实体不再自动获得实体 ID。本地缓存给伪装和预览实体分配独立的负数 ID，
  从整数范围的远端分配，避开服务端的常用 ID 范围，跳过世界中已经占用的 ID。
  末影龙的部件也单独分配 ID，防止渲染及加入世界时读取未分配的 ID。
  创建实体时不再关闭借用的 `ClientLevel`。
- 史莱姆与岩浆怪均继承 `AbstractCubeMob`，岩浆怪不再继承史莱姆。
  `slime_magma/size` 属性改为操作共同基类，继续支持两种实体的非默认尺寸。
- 硫磺立方怪注册基本生物属性集合，支持名称、可见性、装备等通用属性。
  配套服务端只有基本形态及元数据支持，因此没有添加新的尺寸协议或专属技能。
- 界面、提示和 HUD 改用 `Minecraft.gui`，界面变化 Mixin 移至 `Gui.setScreen`。
  相机访问改用 `GameRenderer.mainCamera()`。
- 移除旧 `MultiBufferSource` 路径，光柱继续通过 `SubmitNodeCollector` 提交。
  揭示名称适配新的 `submitNameTag` 参数；挥手动画改在
  `ItemInHandRenderer.submitHandsWithItems` 中修改攻击动画值。
- 移除已废弃且未被消费的 `Tuple` 字段；旧马铠 NBT 路径使用 `EquipmentSlot.BODY`。
- EMF 兼容逻辑改为在 `EMFLODHandler` 上处理新的实体渲染状态；
  EntityCulling 使用当前 `access.Cullable` 接口。EMF 未安装时跳过可选 Mixin。
- 26.2 使用官方名称，无需旧 refmap；Mixin 配置使用 Java 25。

## 与服务端的协议配对

配套插件 `../FeatherMorph` 锁定协议库 `5f6a89f3f0`，接受最高 **API 17**。
客户端协议库 `6ea1669075` 实现 **API 19**，其中包含装备槽及临时属性等后续接口，
直接降级该库会移除客户端正在使用的类。

本分支保留 API 19 的实现，新配置默认开启“协议兼容模式”，在 V3 握手中报告 API 17。
服务端响应仍决定客户端使用哪些同步路径。兼容模式的“恢复默认值”也设为启用。
已经保存 `protocolCompatibilityMode=false` 的用户需要启用该选项并重新连接。
关闭选项仍报告 API 19，供相应服务端使用；当前相邻目录的 API 17 插件会拒绝该握手。

Minecraft 原生网络版本 **776** 与 FeatherMorph 命令 API **17/19** 是两个独立版本号。
本地验证使用原生 26.2 客户端，不依赖 ViaVersion。

## 验证

移植前的 26.1 `./gradlew build --no-daemon` 已通过。26.2 构建和独立测试模组可使用：

```sh
./gradlew build :fabric:prepareUpgradeClientRuntime --no-daemon
DISPLAY=:197 python3 validation/26.2/validate.py
```

测试说明和覆盖范围见 [集成验证](../validation/26.2/README.md)。测试模组单独打包到
`fabric/build/validation`，不会进入生产 JAR；测试从生产 JAR 的嵌套包加载协议库。

[2026-10-10 的本地验证](../validation/26.2/runs/2026-10-10-lophine.md)通过了完整运行的
94 项检查及界面补充运行的 22 项检查，使用两个真实客户端和两种服务端渲染后端。
截图已人工查看；声音播放、完整自定义资源包及全部技能矩阵未覆盖。
